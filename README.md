# FUTURE_DS_03

# 🎓 Task 3 – College Event Feedback Analysis & Sentiment Insights

As part of my **Data Science & Analytics Internship with Future Interns**, this task focused on analyzing student feedback from college events to uncover patterns, satisfaction levels, and improvement opportunities.

---

## ✅ Objective
- Clean and prepare event feedback data  
- Analyze ratings (1–5) for satisfaction trends  
- Perform sentiment analysis (Positive / Neutral / Negative) using TextBlob  
- Visualize results with charts and word clouds  
- Provide insights and actionable recommendations  

---

## 📂 Dataset
- **Event_Feedback.csv** – Contains student ratings and comments collected via Google Forms.  
  - `Event Name`  
  - `Department`  
  - `Rating` (1–5 scale)  
  - `Comment` (open text feedback)  

---

## 🛠 Tools & Libraries
- **Google Colab / Jupyter Notebook**
- **pandas** – data cleaning & preparation  
- **seaborn / matplotlib** – data visualization  
- **TextBlob** – sentiment analysis  
- **WordCloud** – word frequency visualization  

---

## 📊 Key Insights
- ✅ Most ratings are on the higher end (4–5), showing general satisfaction  
- 💬 Positive keywords: *“amazing”*, *“interactive”* | Negative: *“late”*, *“noise”*  
- 🛠 Technical workshops consistently scored highest, while social events had mixed reviews  
- ⚖ Some events had high ratings but neutral sentiment → hidden dissatisfaction  

---

## 🎯 Recommendations
- Replicate practices from top-rated technical workshops  
- Conduct pre-event surveys to align student expectations  
- Improve event logistics (timing, sound, scheduling)  
- Encourage detailed feedback for deeper insights  

---

## 🏁 Final Conclusion
Combining **ratings** with **sentiment analysis** provides a more complete view of student satisfaction.  
Addressing logistical concerns and hidden dissatisfaction will improve event quality and participation in the future.
